# Referencias por unidad

La tabla incluye datos USDA FoodData Central, SR Legacy (abril de 2018). Cada fila con datos identifica el registro original, la porción comestible de referencia y los nutrientes por 100 g. El campo notes conserva la descripción de la medida. Para medidas con varias piezas, weight_avg_g corresponde a una pieza. Una unidad de referencia puede ser un tallo (apio), un diente (ajo) o una mazorca (choclo). El número de unidades se estima a partir de las cajas visibles.

El panel multiplica cantidad × peso unitario en g × kcal por 100 g / 100. Redondea cada renglón y suma los renglones visibles. Unidades sin referencia quedan pendientes. Para calibrar tus propios productos puedes pesar la parte comestible, actualizar weight_avg_g y registrar su procedencia. Reinicia la cámara después de editar la tabla.

Datos: https://fdc.nal.usda.gov/download-datasets/
